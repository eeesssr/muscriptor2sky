# 定调与 `pitchLevel`

本文说明 SkyStudio 谱面里的 `pitchLevel` 字段是什么，以及本工具三种输出模式的区别。

## 结论先行

**`pitchLevel` = 这个谱面要在哪个调上演奏**（相对 C 调的半音数，0~11）。

关键点：**谱面内容永远写成 C 大调形状（do-re-mi），换调靠 `pitchLevel` 声明，而不是把音符改写成别的黑键。**

所以：

| 场景 | 做法 | 需要花货币吗 |
|---|---|---|
| 游戏默认 C 调能弹 | `pitchLevel = 0`（本项目默认） | 不需要 |
| 想整体升 2 个半音 | `pitchLevel = 2` | **需要** |

## 证据（这次找到了确凿对照）

语料里同一首曲子的不同调版本，是天然的对照组：

| 文件 | 文件名标注 | `pitchLevel` | 黑键率 |
|---|---|---|---|
| `Canon卡农_C大调_简易版.txt` | C 大调 | **0** | 0% |
| `Pachelbel's Canon（D大调卡农）.txt` | D 大调 | **2** | **0%** |
| `Lemon(C调).txt` | C 调 | **0** | 0% |
| `星茶会（高音钢琴C调）.txt` | C 调 | **0** | 0% |

两个关键观察：

1. **C → D 正好差 2 个半音，`pitchLevel` 也正好是 0 → 2。** 文件名标注与字段值 4/4 全部吻合。
2. **D 大调版的黑键率是 0%。** 如果它是「把音符改写成 D 大调音阶」，必然出现 F#、C# 等黑键。
   但实测一个都没有，音级分布与 C 大调版几乎一致（C:21% D:12% E:16% F:7% G:15% A:15% B:14%）。

**结论：谱面内容恒定写成 C 大调形状，`pitchLevel` 只是声明「这件乐器/这次演奏整体在哪个调」。**

## 一个重要的纠正

本文件的早期版本曾断言「`pitchLevel` 与音高无关」——**那个结论是错的**。

当时犯错的原因：我用「`pitchLevel` 与实际音域的相关系数」来检验，得到 r≈0.04，据此判定它不表示音高。
这个推理本身有缺陷——**`pitchLevel` 影响的不是「用哪些键」，而是「键盘整体听起来是哪个调」**。
既然所有谱面都写成 C 大调形状，键位分布自然与 `pitchLevel` 无关，相关系数为零是预期结果，
不能用来否证「它是调」。

真正的判据是上面的对照组：文件名标的调与字段值精确对应，且内容黑键率为 0。

## 本工具的三种输出模式

### 1. C 调输出（默认，推荐）

```bash
python -m muscriptor2sky song.mid
```

- `pitchLevel = 0`
- 把所有音塞进最初的 15 个键（C 大调 C4~C6）
- 游戏默认就是 C 调，**不需要花货币兑换**
- 适合绝大多数场景

### 2. 定调输出（指定 `pitchLevel`）

```bash
python -m muscriptor2sky song.mid --pitch-level 2
```

- 谱面内容仍是 C 大调形状（和默认模式完全一样）
- 只是把 `pitchLevel` 写成 2，声明「请把乐器调到 +2 半音」
- **游戏内需要花货币兑换调性**，这就是默认不推荐的原因
- 适用场景：你的乐器已经调在某个调上，想让谱面跟着对齐

### 3. 虚音输出（实验性，`--virtual-notes`）

```bash
python -m muscriptor2sky song.mid --virtual-notes
```

用两个白键同时按下产生的**差音**（difference tone）来"凑"出弹不出的黑键。详见 [虚音说明](虚音说明.md)。

⚠️ **这是实验性功能，实际听感大概率更差。** 物理原因见那份文档，简单说：
差音比基音低 67~102 dB，会被完全掩蔽；而且凑虚音所需的音程本身很刺耳。

## 想换音区（而不是换调）怎么办

**换音区和换调是两件事：**

- 想改变「用到的音高低」（比如整体低一个八度）→ 用 `--root`
- 想改变「演奏的调」→ 用 `--pitch-level`

```bash
python -m muscriptor2sky song.mid --root 72   # 从 C5 开始（更高）
python -m muscriptor2sky song.mid --root 57   # 从 A3 开始（更低）
```

`--root` 会连带重算自动移调，是真正改变输出音高的参数。

## 为什么默认仍然是 0

游戏默认就是 C 调（本项目使用者已确认），而我们的谱面本身已经排成 C 大调白键。
两者天然对齐，**不需要任何额外处理**。

只有在「你的乐器已经调在别的调」时，才需要用 `--pitch-level` 去声明对齐——
并且要接受花货币的代价。
