# 虚音说明（实验性）

`--virtual-notes` 模式试图用**两个白键同时按下**产生的声学效应，来"凑"出 15 键琴弹不出的黑键音。

**先说结论：数学上成立，物理上不成立。这个模式保留下来是为了记录结论，不建议使用。**

## 原理

两个频率为 f1、f2 的音同时发声时，耳内非线性会产生「差音」(difference tone)，频率为 |f2 − f1|。
另有更强的「立方差音」(cubic difference tone)，频率约 2f1 − f2。

如果这两个白键的频率差恰好等于某个缺失半音的频率，理论上就能"听到"那个黑键。

## 计算：确实能找到方案

穷举 15 键的全部两两组合，对每个缺失音级取误差最小的方案：

| 目标音级 | 两键组合 | 产生频率 | 误差 |
|---|---|---|---|
| C# | 键 11 + 键 14（B4 + C6） | 552.62 Hz | **5.5 音分** |
| D# | 键 5 + 键 12（F4 + E5） | 310.03 Hz | **6.1 音分** |
| F# | 键 4 + 键 9（E4 + F5） | 368.83 Hz | **5.5 音分** |
| A# | 键 0 + 键 11（C4 + B4） | 232.26 Hz | **6.1 音分** |
| G# | — | — | 最好 25.9 音分，**不可用** |

人耳的辨别阈值约 20 音分，所以 5~6 音分已经相当准。**单看这张表，方案完全可行。**

## 实测：差音比基音低 67~102 dB

但「算得准」和「听得见」是两件事。

我们用钢琴式谐波叠加合成两个音，做 FFT 后测量目标频率处的实际能量：

| 组合 | 目标处能量（相对较弱的基音） |
|---|---|
| B4 + C6（凑 C#5） | **−93.6 dB** |
| F4 + E5（凑 D#4） | **−77.7 dB** |
| C4 + B4（凑 A#3） | **−67.6 dB** |
| B4 + F5（凑 G#4） | **−102.2 dB** |

**差音比基音低 67~102 dB，相当于小 20 倍到 10 万倍。**

这是**掩蔽效应**（masking），不是音色问题。两个基音同时在响，
人耳根本没有余量去分辨低 70 dB 的成分——理论上「存在」和实际上「能听到」是两回事。

更麻烦的是凑虚音所需的音程：13 半音（大七度）、11 半音（大七度）、14 半音……
全是不协和音程，本身听起来就很刺耳。

## 还有操作层面的问题

游戏里是双拇指触屏。统计 178 份社区谱面的同时按键数：

| 同时按键 | 占比 |
|---|---|
| 1 键 | 60.0% |
| 2 键 | 25.2% |
| 3 键 | 10.9% |
| 4 键以上 | 3.8% |

平均 1.60 键。如果每个黑键音都要占 2 个键，**等于拿掉两根手指去"变"一个听不见的音，
同时旋律本身只剩 1 根手指弹**。

## 那这个模式有什么用

1. **记录结论**：以后有人再提「用组合音凑半音」，这里已经有完整数据和实测，不用重做。
2. **实验平台**：如果你想在别的乐器/音源上验证差音（比如真钢琴、或 sine 波合成），
   这张表可以直接复用。sine 波没有掩蔽问题，差音在纯音下是能听到的。
3. **可弹性评估**：附带产出的 `[可弹性]` 指标有独立价值（见下）。

## 附带的 `[可弹性]` 指标

无论用哪个模式，工具都会输出一行：

```
[可弹性] 旋律可用 15 键弹奏的比例 95.7%
```

这个比例 = 1 − 被半音吸附的音 / 总音符数。**它回答的是「这首歌适不适合 15 键琴」**：

| 可弹性 | 含义 |
|---|---|
| > 95% | 调性音乐，转换基本忠实 |
| 85%~95% | 有离调音，会有明显改动 |
| 70%~85% | 半音化较重，建议降期望 |
| < 70% | 不适合 15 键琴，建议换曲 |

参考实测值：

| 曲目 | 最佳音阶覆盖率 |
|---|---|
| Flower Dance | 98.2% |
| 洛天依 - 纯蓝 | 98.0% |
| DAMIDAMI | 95.6% |
| 洛天依 - 蝴蝶 | 83.6% |
| Relaxu - 星降る海 | **68.3%** ← 换成谁都救不回来 |

## 如果你真的想试

```bash
python -m muscriptor2sky song.mid --virtual-notes
```

输出末尾会显示为多少个黑键音补了组合键。建议**戴耳机、安静环境**下试听——
这是差音最容易被察觉的条件。如果在安静环境下都听不出来，游戏里就更不可能。
